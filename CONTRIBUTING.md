This is a personal fork focused on a specific goal — a PowerPC/Intel fat-binary
port of Aleph One for vintage Mac hardware — not a general contribution target.

If your change is relevant to Aleph One generally (not PPC/old-Mac specific),
please send it to the upstream project instead:
[Aleph-One-Marathon/alephone](https://github.com/Aleph-One-Marathon/alephone).
Upstream does not accept patches originating from porting projects like this one,
so changes made here don't flow back — this fork stays a fork by design.

Issues specific to this port (old-Mac build/runtime problems) are welcome on
this repo's own issue tracker.
